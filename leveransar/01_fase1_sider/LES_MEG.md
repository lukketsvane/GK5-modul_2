# Fase 1-sider

Sju sider i 1127 x 797 px, same storleik som rammene i klassefila i Figma. Ingenting her er lagt inn i klassefila. Du dreg sjølv bileta i `png/` inn i rammene dine.

| Fil | Innhald |
| --- | --- |
| side-1-debrief | Debrief, åtte punkt |
| side-2-bransjeresearch | Research i bransjen og systemkomponentar |
| side-3-3b-analyse | Brukar, brukssituasjon, bruksmåte og døgnlinje |
| side-4-kravspesifikasjon | Fem kategoriar gonger skal, bør, kan |
| side-5-berekraftshandling | Handling for berekraft |
| side-6-prosjektplan | Tidsplan, førehandsprøver, risiko |
| side-7-bedriftsbesok | Bedriftsbesøk i Ålesund-regionen, skrivebordsresearch |

Teksten ligg i HTML-filene, stilen i `felles.css`. Kjeldeteksten ligg i `grunnlag/`.

Lag eit bilete på nytt etter ei endring: `sh lag-png.sh side-3-3b-analyse`. Biletet blir 2254 x 1594 px.

Skrift: EB Garamond (i `fonts/`, OFL-lisens) og Consolas. Berre svart, kvitt og grått.
