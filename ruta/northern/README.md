# RUTA | Design proposal for Northern

A three-page PDF and a 14-image website based on the revision C CAD model.

- RUTA-Northern-design-proposal.pdf: short external design proposal.
- index.html: visual presentation with one CAD render per section.
- model.html: interactive revision C assembly, tilt and finish studies.
- ruta-c.glb: Blender-exported revision C assembly with 20 CAD objects.
- images/: fourteen 1920 x 1200 CAD renders.
- previews/: verified desktop and mobile screenshots, plus PDF previews.
- render_c_northern.py (in the CAD directory): repeatable Blender renderer.

The product shown is an unbuilt design concept. Light diffusion, warm-white emission, thermal behavior, tip resistance, finish and safety have not been physically tested. The prototype uses recovered monitor optics and a low-cost RGB light source; the depicted warm light is an illustration, not a measurement.

The 2027 Designers' Saturday Northern brief is for pendant lamps, while RUTA is a table lamp. Submit as a separate unsolicited proposal, not as an entry to that competition.

Before sharing the entire editable CAD or discussing licensing, review ownership and design registration. This public repository has already disclosed the design. Confirm first public disclosure date.

Proposal prepared, not sent to Northern.
