# Formføringsplansje, første versjon

To sider i 1127 x 797 px, til Moodle 17.11 og formgjennomgangen 25.11. Same stil som fase 1-sidene: figuren først, på svart.

| Fil | Innhald |
| --- | --- |
| side-8-formfoering-sortiment | Seks Northern-lamper i same målestokk, proporsjonsrommet (lyshovud mot fot) og regeltesten på 18 lamper |
| side-9-formfoering-ny-lampe | Poengskalaen for endring og attkjenning, dei tre verdiorda med det dei utelukkar, og det som må haldast, kan vere nytt eller aldri skal skje |

Innhaldet kjem frå `grunnlag/07-formfoering.md`. Måla er frå produktarka til Northern, lesne 12.11.2026. Silhuettane er skjematiske: primitivane lampa er bygd av, i målestokk. Fothøgda på Snowball oppladbar og Buddy og bøyen på Buddy er omtrentlege, for produktarka gjev dei ikkje.

Formatet er ikkje fastsett i kursmaterialet. Spørsmåla til formlæraren står nedst til høgre på side 9.

Lag sidene på nytt:

```
python lys/bygg_formfoering.py
sh lag-png.sh side-8-formfoering-sortiment
sh lag-png.sh side-9-formfoering-ny-lampe
```
